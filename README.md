# Siyu Chen academic homepage

Live website: https://sosekichen-maker.github.io/

Ph.D. Candidate in Mechanical Engineering, Villanova University.
Research in biomechanics, deep brain stimulation, fluid–structure interaction, and particle transport.

## Preview and maintenance

Run `node scripts/preview.mjs` to preview locally and `node scripts/check.mjs` to validate local paths.
Edit the biography in `index.html`, research and profile links in `data/site.js`, and publication records in `data/publications.js`.
Journal records sort by `published_date` (first online publication, YYYY-MM-DD). Conference presentations and posters have their own sections.
To update the portrait, replace `assets/images/profile.webp` or update `portrait` in `data/site.js`.
The active CV is `assets/cv/Siyu_Chen_CV_09_2026.pdf`. For a new version, update `links.cv`, the fallback CV links in `index.html`, and the revision note in `js/main.js`.

## Hosting

GitHub Pages: Deploy from a branch, main, /(root). No build tools or backend are required.
Scientific figures retain their source credits. The website does not grant a new license to third-party publication images.
